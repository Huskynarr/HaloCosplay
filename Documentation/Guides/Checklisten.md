# Checklisten

Diese Listen helfen, nichts zu vergessen. Drucke sie aus oder nutze sie als Issue-Vorlage.

## Planung

- [ ] Variante gewaehlt (V1/V2/V3)
- [ ] Con-Regeln geprueft
- [ ] Budget + Zeitplan abgestimmt
- [ ] Messungen genommen
- [ ] Tragesystem entworfen

## Bau (Ruestung/Helm)

- [ ] Testteile aus Karton/Foam
- [ ] Passform getestet (Sitzen, Treppen, Drehen)
- [ ] Versiegelung vor Lack
- [ ] Lack in mehreren duennen Schichten
- [ ] Schnellverschluesse und Notausstieg

## Elektronik

- [ ] Strombudget kalkuliert
- [ ] Akku mit Schutzschaltung
- [ ] Kabelwege und Strain-Relief
- [ ] Elektroniktest ausserhalb der Ruestung
- [ ] Lueftertest (Temperatur)

## Con-Ready

- [ ] Sichtfeld getestet
- [ ] Prop-Waffe konform
- [ ] Handler organisiert (falls noetig)
- [ ] Ersatzteile: Klett, Tape, Kabel, Akku
- [ ] Wasser, Pausenplan

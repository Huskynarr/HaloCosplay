# Checklisten

> **Level:** [A] Anfaenger | [F] Fortgeschritten | [P] Profi  ·  **Varianten:** alle

Diese Listen helfen, nichts zu vergessen. Drucke sie aus oder nutze sie als Issue-Vorlage.

## Planung

- [ ] Variante gewaehlt (V1/V2/V3)
- [ ] Con-Regeln geprueft (siehe `Convention-Regeln.md`)
- [ ] Budget + Zeitplan abgestimmt
- [ ] Messungen genommen (Brust, Taille, Huefte, Arme, Beine, Kopf)
- [ ] STL-Set ausgewaehlt und heruntergeladen
- [ ] Tragesystem entworfen (Klettergurt/MOLLE + Klett/Magnete)

## 3D-Druck (H2C)

- [ ] Filament bestellt (mind. 4 kg PETG)
- [ ] Bambu Studio Projekt angelegt (Multi-Plate)
- [ ] STLs skaliert auf eigene Masse
- [ ] Teile gesplittet die nicht ins Bauvolumen passen
- [ ] Testdruck eines kleinen Teils (Passform + Einstellungen)
- [ ] Alle Teile gedruckt (siehe `Documentation/TODO.md`)
- [ ] Teile zusammengeklebt (CA + Epoxy)
- [ ] Passform-Test mit Rohteilen

## Oberflaechenbearbeitung

- [ ] Schleifen 120 > 240 > Filler Primer > 320 (2-3 Zyklen)
- [ ] Naehte gespachtelt (Bondo/XTC-3D)
- [ ] Finale Grundierung
- [ ] Grundfarbe aufgetragen (Oregano Satin)
- [ ] Sekundaerfarben (Schwarz, Gunmetal)
- [ ] Weathering (Wash, Dry Brush, Battle Damage)
- [ ] Klarlack-Versiegelung (matt)

## Visor

- [ ] PETG-Folie besorgt
- [ ] Visor-Buck gedruckt
- [ ] Vakuum geformt
- [ ] iDye Poly Gold gefaerbt
- [ ] Krylon Looking Glass innen verspiegelt
- [ ] Im Helm eingepasst

## Elektronik

- [ ] Strombudget kalkuliert (siehe `Elektronik-Strombudget.md`)
- [ ] Akku mit Schutzschaltung (PiSugar oder Powerbank)
- [ ] Pi eingerichtet (OS, I2C, Python, Autostart)
- [ ] OLED getestet (i2cdetect)
- [ ] Arduino geflasht (LEDs, Luefter)
- [ ] LEDs verloetet und getestet
- [ ] Luefter montiert und getestet
- [ ] Kabelwege und Strain-Relief (JST/XT30)
- [ ] Quick-Disconnect am Helm-Nacken
- [ ] Elektroniktest ausserhalb der Ruestung
- [ ] Lueftertest (Temperatur im Helm)
- [ ] Laufzeittest (mind. 4 Stunden)

## Unteranzug und Befestigung

- [ ] Unteranzug besorgt (feuchtigkeitsableitend!)
- [ ] Klettergurt/MOLLE-Guertel montiert
- [ ] Klett-Punkte aufgenaecht
- [ ] Magnete eingeklebt (Polaritaet markiert!)
- [ ] Polsterung in Ruestungsteilen
- [ ] Helm-Padding + Kinnriemen
- [ ] Kabelwege im Unteranzug (Spiralschlauch)

## Integrationstest

- [ ] Komplettanzug mit Handler anziehen
- [ ] Sichtfeld (Treppen, Tueren, Engstellen)
- [ ] Beweglichkeit (Sitzen, Drehen, Hocken)
- [ ] Toilette erreichbar ohne Komplett-Demontage
- [ ] Elektronik-Gesamttest
- [ ] Notausstieg funktioniert
- [ ] Gewicht unter 20 kg

## Con-Ready

- [ ] Sichtfeld getestet
- [ ] Prop-Waffe konform (Con-Regeln geprueft)
- [ ] Handler organisiert
- [ ] Fotos an Con gesendet (Vorab-Freigabe)
- [ ] Reparatur-Kit gepackt (siehe unten)
- [ ] Ersatz-Akkus geladen
- [ ] CamelBak/Trinkblase
- [ ] Wasser, Elektrolyte, Snacks
- [ ] Transport-Boxen mit Polsterung
- [ ] Props in blickdichten Taschen (Waffengesetz!)

# Waffen-Prop (Master Chief)

Ziel ist eine sichere, konforme Prop-Waffe mit authentischer Silhouette.

## Bauoptionen

- EVA-Foam + PVC-Rohr als Kern (leicht, con-sicher)
- 3D-Druck-Teile fuer Details (Magazin, Rails)
- Holzkern nur wenn erlaubt und voll ummantelt

## Sicherheit

- Keine scharfen Kanten
- Keine Metallteile an der Spitze
- Farbe/Finish so, dass es klar als Prop erkennbar ist

## Finish

- Grundierung + Metalllack + Weathering
- Matte Klarlackschicht zum Schutz

## Elektronik (optional)

- LEDs fuer Visierung
- Soundmodul mit Halo-Sounds (leise)

# Glossar

Begriffe die in diesem Projekt verwendet werden.

## Materialien und Bau

| Begriff | Erklaerung |
| --- | --- |
| **EVA-Foam** | Ethylen-Vinyl-Acetat Schaumstoff, Standard-Material fuer Cosplay-Ruestung |
| **PLA/PLA+** | Polylactide, gaengigstes 3D-Druck-Filament, einfach zu drucken, hitzeempfindlich |
| **PETG** | Polyethylenterephthalatglycol, schlagfestes Filament, empfohlen fuer tragbare Ruestung |
| **ASA** | Acrylnitril-Styrol-Acrylat, UV-bestaendiges Filament, braucht Enclosure |
| **TPU** | Thermoplastisches Polyurethan, flexibles Filament fuer Dichtungen/Gelenke |
| **Bondo** | Autospachtel-Marke, fuellt Naehte und Luecken in 3D-Drucken |
| **XTC-3D** | Epoxy-Beschichtung (Smooth-On) zum Glaetten von 3D-Drucken |
| **CA-Kleber** | Cyanacrylat / Sekundenkleber |
| **Plasti-Dip** | Gummibeschichtung zum Versiegeln von Foam vor dem Lackieren |
| **Filler Primer** | Grundierung die kleine Unebenheiten (Layer Lines) ausfuellt |
| **Heat-Seal** | Foam-Oberflaeche kurz mit Heissluft verschliessen (Poren schliessen) |

## Elektronik

| Begriff | Erklaerung |
| --- | --- |
| **I2C** | Inter-Integrated Circuit, Kommunikationsprotokoll (SDA + SCL Leitungen) |
| **SPI** | Serial Peripheral Interface, schnellere Alternative zu I2C |
| **SSD1309** | OLED-Display-Controller fuer transparente 1.51" Displays |
| **WS2812B** | Adressierbare RGB-LED (auch "NeoPixel"), jede LED einzeln steuerbar |
| **SK6812** | Wie WS2812B, aber mit zusaetzlichem weissem Kanal (RGBW) |
| **PWM** | Pulsweitenmodulation - Helligkeits-/Geschwindigkeitsregelung |
| **BMS** | Battery Management System, Schutzschaltung fuer LiPo-Akkus |
| **UBEC** | Universal Battery Eliminator Circuit, Spannungsregler |
| **JST-XH** | Steckertyp fuer Signalleitungen (bis 3A) |
| **XT30/XT60** | Steckertyp fuer Stromleitungen (30A/60A Belastbarkeit) |
| **Level Shifter** | Wandelt Signalpegel um (z.B. 3.3V Pi -> 5V LEDs) |
| **Strain Relief** | Zugentlastung an Kabeln/Steckern |

## 3D-Druck

| Begriff | Erklaerung |
| --- | --- |
| **Infill** | Fuellstruktur im Inneren eines 3D-Drucks (% = Dichte) |
| **Gyroid** | Infill-Muster mit gleichmaessiger Festigkeit in alle Richtungen |
| **Tree Supports** | Baumartige Stuetzstrukturen, leichter zu entfernen als Block-Supports |
| **Brim** | Flacher Rand um das Druckobjekt fuer bessere Haftung |
| **Z-Seam** | Vertikale Nahtlinie wo jede Schicht beginnt/endet |
| **Elephant's Foot** | Leichte Verdickung der ersten Druckschicht |
| **Layer Lines** | Sichtbare horizontale Linien vom Schichtaufbau |
| **Arachne** | Wandgenerator in Bambu Studio fuer variable Wandstaerken |

## Cosplay / Convention

| Begriff | Erklaerung |
| --- | --- |
| **Handler** | Begleitperson die dem Cosplayer bei Navigation und Logistik hilft |
| **Peace-Binding** | Markierung dass ein Prop geprueft und freigegeben wurde |
| **Anscheinswaffe** | Gegenstand der einer echten Waffe aehnelt (Par. 42a WaffG) |
| **Masquerade** | Cosplay-Wettbewerb auf Conventions (oft mit Buehnen-Performance) |
| **DCM** | Deutsche Cosplay Meisterschaft |
| **405th** | 405th Infantry Division - die primaere Halo-Cosplay-Community |
| **RPF** | Replica Prop Forum - grosse allgemeine Prop-Bau Community |

## Ruestung (Halo-spezifisch)

| Begriff | Erklaerung |
| --- | --- |
| **MJOLNIR** | Mark-Bezeichnung der Spartan-Ruestung in Halo |
| **Mark V/VI/VII** | Verschiedene Generationen der MJOLNIR-Ruestung |
| **GEN3** | Dritte Generation MJOLNIR (Halo Infinite) |
| **Pauldron** | Schulter-Ruestungsteil |
| **Codpiece** | Ruestungsteil im Hueft-/Schrittbereich |
| **Gorget** | Hals-/Nacken-Ruestungsteil |
| **Visor Buck** | Positivform zum Vakuumformen des Helm-Visiers |
| **Undersuit / Tech Suit** | Enganliegender Anzug unter der Ruestung |

# Lokale Schriften

Latin-Subsets (WOFF2) von Google Fonts, lokal ausgeliefert, damit die Seite
keine Verbindung zu Google aufbaut. `fonts.css` bindet sie ein.

| Schrift | Dateien | Lizenz |
| --- | --- | --- |
| Barlow 400/500/600 | `barlow-*.woff2` | SIL OFL 1.1, `barlow-OFL.txt` |
| Chakra Petch 500/600/700 | `chakra-petch-*.woff2` | SIL OFL 1.1, `chakrapetch-OFL.txt` |
| JetBrains Mono 400-600 (variabel) | `jetbrains-mono-var.woff2` | SIL OFL 1.1, `jetbrainsmono-OFL.txt` |

Weitere Schnitte oder Zeichenbereiche (zum Beispiel latin-ext) als eigene
`@font-face`-Regel mit passender `unicode-range` ergaenzen.

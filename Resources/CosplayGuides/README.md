# Offizielle 343-Cosplay-Guides

343 Industries hat fuer Cosplayer **offizielle Referenz-PDFs** zum Mark VII
veroeffentlicht. Das Repository verlinkt sie nur; die Dateien selbst liegen beim
Herausgeber. "Halo", "Master Chief" und "MJOLNIR" sind Marken von
Microsoft/343 Industries - die Nutzung hier erfolgt als nicht-kommerzielles
Fan-Projekt.

## Quelle

- **Autor:** Andy Salisbury (Community Communications Manager, 343 Industries)
- **Titel:** Official Cosplay Guide: MARK VII
- **Veroeffentlicht:** Juni 2021, anlaesslich der Halo-Infinite-Multiplayer-Reveal
- **Original-Artikel (Halo Waypoint Blog):** https://www.halowaypoint.com/en-us/news/official-cosplay-guide-mark-vii

Beide Links wurden zuletzt am 22.11.2026 geprueft (HTTP 200). Aendert 343 die
Adressen, fuehrt der Waypoint-Artikel zu den aktuellen Dateien.

## Offline-Kopie fuer die Convention

Auf Cons gibt es oft kein Wlan. Die PDFs deshalb vorher auf das eigene Geraet
laden. Wer sie neben dem Repository ablegen will, speichert sie in diesem Ordner;
`*.pdf` ist hier per `.gitignore` von Commits ausgenommen:

```bash
curl -L -o Resources/CosplayGuides/MK7_CosplayGuide_Full.pdf "https://content.halocdn.com/media/Default/community/CosplayGuides/mk7_cosplayguide_fullsize-a95f71a129ae4094aef3ea0b6121fca4.pdf"
curl -L -o Resources/CosplayGuides/MK7_CosplayGuide_Mobile.pdf "https://content.halocdn.com/media/Default/community/CosplayGuides/mk7_cosplayguide_mobile-c9b71de988af42f9b6f6010ef44a2417.pdf"
```

## Warum nicht mehr im Repository?

Die beiden Dateien machten 64 von 87 MB des Repositories und jedes
Web-Deployments aus, und eine Weiterverbreitung durch Dritte ist vom Herausgeber
nicht ausdruecklich erlaubt. Die Seitenangaben in
[Authentizitaet-Referenz](../../Documentation/Guides/Authentizitaet-Referenz.md)
beziehen sich weiter auf die Full-PDF.

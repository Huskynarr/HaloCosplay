## Empfehlung: Minimum-Toolkit V2

Fuer einen 3D-Druck-basierten Build (V2) brauchst du mindestens:

1. Loetstation + Loetzinn + Multimeter
2. Dremel + Schleifpapier-Set
3. CA-Kleber + Epoxy
4. Atemschutz + Handschuhe
5. Filler Primer + Spruehlack (Oregano Satin)
6. Massband + Messschieber

Alles andere ist "nice to have" und kann schrittweise ergaenzt werden.
